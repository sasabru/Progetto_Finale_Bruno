## Descrizione del progetto
Questo progetto implementa una piattaforma integrata per la gestione e l'analisi dei dati del servizio di mobilità condivisa *VeloCittà*. Sfruttando un approccio multidisciplinare, il repository include moduli a oggetti (OOP) per simulare lo stato in tempo reale di mezzi e flotte, script SQL per interrogare i database relazionali storici, e pipeline di Data Science per la pulizia, l'aggregazione statistica e la visualizzazione finale dei KPI di business.

## Istruzioni per l'installazione

Prima di eseguire gli script, è necessario configurare l'ambiente installando i pacchetti software richiesti. Apri il terminale nella cartella principale del progetto ed esegui il seguente comando:

pip install -r requirements.txt

## Esecuzione corretta degli script:
main_oop.py --> main_analisi.py
main_oop.py: contien tutto quello che riguarda la parte di OOP
main_analisi.py: contiene tutto quello che riguarda invece di analisi numerica con NumPy, la manipolazione dati, la pulizia e il merge dei DataFrame   con Pandas, generando infine la dashboard grafica salvata nella cartella di output

python main_oop.py
python main_analisi.py
